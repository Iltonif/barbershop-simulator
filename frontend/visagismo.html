Análisis de visajismo

Rasgos faciales (nariz, ojos, orejas, cejas, simetría, gafas) para afinar las recomendaciones de corte de este cliente. A partir de las fotos, el sistema estima la simetría y separación de los ojos y si lleva gafas; el resto se rellena a mano. Todo es revisable después.

Análisis automático (opcional)

3 fotos con buena luz. Lo importante es la frontal: cliente mirando directamente a la cámara, sin girar la cabeza. Las de perfil todavía no se analizan automáticamente (nariz y orejas se rellenan a mano). Las fotos se analizan al vuelo y no se guardan en ningún sitio — solo se guarda el resultado ya resumido.

    Nariz y perfil

    Se rellena a mano, mirando al cliente de perfil.

    Ojos y cejas

    Se rellena a mano: las fotos no permiten detectarlo con fiabilidad.

    Orejas, cuello y otros

    Se rellena a mano, mirando al cliente de frente.
